How to Install TrollStore

Choose your method: TrollHelperOTA, TrollInstallerX, or TrollRestore. Step-by-step for supported iOS versions.

This section explains how to install TrollStore using the installer that matches your iOS version. There is no single universal method, and using the wrong installer is the most common cause of failure. The steps below cover the no-PC OTA method, TrollInstallerX, and TrollRestore, along with version-specific notes for iOS 15 and iOS 16. The official README also points to ios.cfw.guide for version-specific walkthroughs.

About "direct install" and download links: A direct install does not mean tapping a single link that installs the app. There is no one-tap package for TrollStore. "Direct install" here means installing on-device with the correct installer for your version—TrollHelperOTA (no PC), TrollInstallerX, or TrollRestore. For the official files, use the GitHub Releases page at github.com/opa334/TrollStore/releases.

Method A: TrollHelperOTA — Install TrollStore Without a PC (iOS 14.0 beta 2 – 15.6.1)

This is the only no-PC install path, and the simplest way to install TrollStore without a computer on the versions it covers. It requires no computer at all.

  1. Open Safari on your device.
  2. Navigate to the TrollHelperOTA link appropriate for your chip (arm64e devices use OTA Link 2; iOS 15+ devices use OTA Link 1).
  3. Tap Install. An app named "GTA Car Tracker" appears on your home screen.
  4. Open it and tap Install TrollStore.
  5. The device resprings, and TrollStore is installed.

Limitations: arm64 (A8–A11) devices on iOS 14 cannot use OTA. They require a checkra1n jailbreak first, then the TrollHelper install. On iOS 16.0 and later, OTA installation is often unstable or patched; TrollInstallerX with a computer is strongly recommended for those versions. If you are on iOS 15.7.2 or later, skip to Method B.

Method B: TrollInstallerX — The Standard Way to Install TrollStore With a PC (iOS 14.0 – 16.6.1, and 17.0)

This is the widest-coverage installer and the standard path with a computer on supported versions. The installer file is TrollInstallerX.ipa, which you download from the official GitHub releases page. TrollInstallerX supports arm64 devices up to iOS 16.6.1 and arm64e devices up to iOS 16.5.1; A15, A16, and M2 devices on iOS 16.5.1 require the indirect installation method.

  1. Download TrollInstallerX.ipa from the official GitHub releases page.
  2. Sideload it to your device using Sideloadly or a similar signing tool.
  3. Open TrollInstallerX and tap Install TrollStore.
  4. The installer automatically selects the appropriate exploit for your device. TrollStore appears on the home screen when complete.

iOS 26 and iOS 18: a direct install does not exist on these versions. TrollStore requires the CoreTrust bug, which Apple patched in iOS 17.0.1. The available alternatives are SideStore or Sideloadly, or TrollStore Lite on a jailbroken device (see the Variants page).

Note: iOS 16.2–16.6.1 and iOS 15.7.2–15.8.2 require an internet connection during installation so TrollInstallerX can download the kernelcache and patchfind it.

Method C: TrollRestore (iOS 15.2 beta 3 – 16.6.1, 16.7 RC, 17.0; Computer Required)

For the narrow set of versions not covered by TrollInstallerX, TrollRestore provides a computer-assisted path. This requires a Mac, PC, or Linux machine with a data cable, plus Python 3. Detailed instructions are available on the tool's release page and ios.cfw.guide.

Install TrollStore by iOS Version: iOS 15, iOS 16, and iOS 15.8.x

  • iOS 15: on iOS 15.0–15.6.1, use Method A (TrollHelperOTA, no PC). On iOS 15.7.2–15.8.8, use Method B (TrollInstallerX, internet required during install).
  • iOS 16: use Method B (TrollInstallerX). On iOS 16.7 RC (20H18), Method C (TrollRestore) is the recommended path; non-RC 16.7.x is not supported.
  • iOS 15.8.2 – 15.8.8: Method B (TrollInstallerX), internet required during install. This range covers every point release from 15.8.2 through 15.8.8.
  • TrollStore 2 without a PC: on iOS 14.0–15.6.1 you can install without a PC via Method A; on iOS 16.0+ a computer (Method B) is required. There is no separate installer for this.
  • Current version (2026): the latest release is 2.1.1, and the installation methods above are unchanged. Always confirm the current version on the GitHub Releases page.

The Persistence Helper: Why TrollStore Sometimes "Stops Working"

After installation, iOS periodically reloads its icon cache. When this happens, TrollStore and the apps it installed can revert to "User" state and stop launching. This is normal. The fix is the Persistence Helper: TrollStore replaces a built-in system app (typically Tips) with a small helper. When your apps stop opening, open the helper app and tap Refresh App Registrations. You still need this helper once, even if you installed TrollStore without a computer.
