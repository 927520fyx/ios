What Is TrollStore? A Complete Guide to iOS Permanent Sideloading (2026)

TrollStore is an on-device iOS tool that permanently installs IPA apps without the 7-day certificate renewal required by standard sideloading. It works by exploiting CoreTrust code-signing vulnerabilities, and it is limited to specific older iOS versions.

What Is TrollStore?

TrollStore is an open-source sideloading tool developed by the GitHub user opa334. Unlike most sideloading methods, it does not require an Apple Developer account or periodic re-signing. Apps installed through TrollStore remain on the device until they are manually removed.

How Does TrollStore Work?

Normally, iOS checks that every app is signed with a valid certificate. TrollStore takes advantage of flaws in how CoreTrust validates code signatures, specifically bugs involving multiple-signer validation. By exploiting these flaws, TrollStore can register IPA files as trusted system-level apps.

Apple has patched these flaws in newer firmware, which is why support is restricted to specific versions.

How to Install TrollStore

  1. Confirm that your device runs a supported iOS version (see the table above).
  2. Choose an installation method that matches your device and iOS version. Options include TrollInstallerX and other community-maintained installers.
  3. Follow the installer's instructions to apply the CoreTrust exploit and install the TrollStore app.
  4. Open TrollStore and use it to install IPA files.
Installation steps depend on the method and version you use. Check the official project page before proceeding.

Is TrollStore Safe and Legal?

TrollStore relies on exploiting security vulnerabilities, which carries inherent risks. Keep the following in mind:

  • Security: Bypassing code-signing protections can allow malicious or untrusted apps to run with elevated privileges. Only install IPAs from sources you trust.
  • Device stability: Installing an exploit-based tool on an unsupported build can cause instability or data loss. Back up your device first.
  • Legality: Sideloading is permitted in many regions, but using it to pirate software, bypass payment, or violate terms of service is not. Check the laws in your country and the terms of any app you install.
  • Updates: Apple may patch the vulnerability in any future update, so check compatibility before upgrading iOS.

Frequently Asked Questions

Is TrollStore free?

Yes. TrollStore is an open-source project, although some installers may be provided by third parties.

Does TrollStore require a jailbreak?

No. TrollStore is a non-jailbreak method that uses a CoreTrust exploit to install apps. It does not modify the core iOS system the way a jailbreak does.

Will TrollStore work on the latest iOS?

No. As of November 2026, TrollStore only supports iOS 14.0 beta 2 through 16.6.1, iOS 16.7 RC (build 20H18), and iOS 17.0.

Does TrollStore expire?

No. Apps installed through TrollStore stay on the device until you remove them, unlike free-account sideloaded apps that expire after 7 days.

Conclusion

TrollStore offers permanent app installation on a limited set of older iOS versions by exploiting CoreTrust signing flaws. Before installing it, confirm your iOS version, understand the security trade-offs, and only use it within the law.
