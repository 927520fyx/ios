Capabilities, Mechanism & Computer-Free Sideloading

  • TrollStore is a permasigned jailed application for iOS. It allows you to permanently install and sign any IPA file without weekly PC re-signing or a 7-day expiration limit.

    Key benefits include:

    • Full rootless entitlements
    • Working push notifications
    • Support for advanced system tools

  • TrollStore works under the hood by exploiting the CoreTrust vulnerability (CVE-2023-41991) in iOS code signature verification. It injects binaries and registers them with full rootless entitlements, tricking the iOSinstalld service and CoreTrust verification mechanism into treating any installed app as a system-signed or developer-trusted application. This completely bypasses standard sandbox restrictions and expiration limits without requiring a persistent jailbreak.

iOS Compatibility, Downloads & Updates

  • You can download official TrollStore releases, helper files, and IPA packages directly from developer @opa334's official GitHub repository.

  • If you update your device to iOS 17.1, iOS 18, or newer versions, Apple has patched the CoreTrust bug, which will permanently break and disable TrollStore functionality.
