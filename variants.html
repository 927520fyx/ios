TrollStore Versions Explained: Standard, Lite and 2.1.1

Last updated: November 19, 2026

Short answer: TrollStore has two official forms. The standard app does not require a jailbreak but supports only specific iOS versions. Lite requires a jailbreak and is installed as a .deb package from the Havoc repository. The latest stable release is 2.1.1. No official Pro or Mod version exists, and downloads claiming to be either should not be trusted.

Official Versions at a Glance

TrollStore's version numbers follow a 2.x line. "2", "v2" and "2.x" all refer to the same series, not to different products. The table below lists the releases that matter most to users.

Version Release Key Changes
2.0 2023 Added use of CVE-2023-41991, extending support to iOS 16.6.1, 16.7 RC and 17.0
2.1 September 2, 2024 Introduced TrollStore Lite for jailbroken devices and added app transfer between TrollStore installations
2.1.1 April 1, 2026 Fixed an entitlement typo affecting Lite and a UI bug where icons of newly installed or removed apps did not update

The full release history is available on the official GitHub Releases page. The 2.1 notes describe the introduction of Lite, and the 2.1.1 notes list fixes for both TrollStore and TrollStore Lite.

Standard App vs. Lite: What Differs

Both the standard app and Lite can permanently install signed IPA files on a device, but their prerequisites and supported range are entirely different. The standard app exploits the CoreTrust bug (CVE-2023-41991) to bypass signature validation and does not need a jailbreak. Apple has since fixed that bug in later system updates. Lite relies on the signature bypass provided by a jailbreak, so its availability depends on whether a compatible jailbreak exists for the device's iOS version.

The standard app's supported range matches the TrollStore entry on The Apple Wiki. Apple's fix for CVE-2023-41991 shipped in iOS 17.0.1, as described in the Apple security notes for iOS 17.0.1, which is why the standard app cannot be used on 17.0.1 and later.

How to check your situation: If your device is not jailbroken and runs an iOS version outside the standard app's supported range, this guide cannot help you install TrollStore directly. The alternatives page covers other sideloading options.

iOS Versions Supported by the Standard App

The standard app supports iOS 14.0 beta 2 through 16.6.1, 16.7 RC (20H18) and 17.0. The installation method varies by system version, and the step-by-step instructions are in the installation guide. On devices outside this range, a downloaded installer will not produce a permanently signed app, so unofficial "universal" builds are not a safe workaround.

Installing and Using Lite

Lite is the official build for jailbroken devices. It is distributed as a .deb package and installed only through a package manager such as Sileo or Cydia, from the Havoc repository. It is not an IPA file, and attempting to sideload a .deb as an IPA will not work. The TrollStore Lite page on Havoc lists the supported iOS range as 14.0 to 26.0.1 and states that a jailbreak is required.

On some jailbreak setups, such as those built on the roothide architecture, Lite may behave inconsistently. If icons do not appear or apps fail to register, first confirm that the jailbreak itself is stable, then make sure you are running the latest Lite release.

Caution: Any website offering a "Lite IPA" is not affiliated with the official project. Lite is distributed only through the Havoc repository.

Beta and Pre-release Builds

Beta builds are development snapshots that the developer occasionally publishes on the GitHub Releases page as pre-releases. They are not a separate product line and do not change the supported systems or the installation method, but they may contain unresolved bugs. Most users should install the latest stable release, 2.1.1. A pre-release is worth trying only when a maintainer specifically asks you to test it while troubleshooting a particular issue.

About "Pro" and "Mod" Builds

Names such as "TrollStore Pro", "Pro IPA", "TrollStore Mod" and "Mod IPA" circulate online, but none of them are official. The developer, opa334, has not released a paid edition or a modified edition, and TrollStore is a free, open-source project.

These unofficial installers carry real risk. TrollStore's core function is bypassing Apple's signature validation, so a tampered installer can gain very high system privileges. Third-party modified builds may include malicious code, steal personal data, install unknown configuration profiles or break existing functionality on the device. The standard app already provides permanent signing, app transfer and refresh, so there is no good reason to download an untrusted build for supposed extra features.

Reminder: Download the standard app only from the official GitHub Releases page, and install Lite only from the Havoc repository. Any other source is not an official channel.

Choosing the Right Version

If your device is not jailbroken and runs an iOS version within the standard app's range, use the standard app and download the latest stable release from the official GitHub page. If your device is already jailbroken and you want TrollStore's features inside that environment, Lite is the option, but first confirm that your current jailbreak supports your iOS version. If your system version falls outside both categories, neither official version will work for you, and the alternatives page lists other options.

Frequently Asked Questions

Is TrollStore Lite the same as the standard app?

No. The standard app uses the CoreTrust bug, does not require a jailbreak, and supports only specific iOS versions. Lite requires a jailbreak and is installed as a .deb package from the Havoc repository.

Can I use TrollStore Lite without a jailbreak?

No. Lite depends on the jailbreak environment and cannot be installed on a non-jailbroken device.

Do TrollStore Pro or Mod versions exist?

No official version of either exists. Sites that offer them are not affiliated with developer opa334, and their installers may contain malicious code. Do not download them.

Is there a difference between TrollStore 2 and v2?

No. Both refer to the 2.x release line, and the latest stable version is 2.1.1.

Should I install a beta build?

Usually not. Unless a maintainer specifically asks you to test a pre-release to solve a particular problem, use the latest stable release.
